# Myra Harris Relationship Coaching

Website for [Myra Harris Relationship Coaching](https://myraharriscoaching.com/) — a certified relationship coaching practice based in St. Louis, MO, specializing in communication and listening skills for women in romantic relationships.

## Tech Stack

- **Build tool**: [Vite](https://vitejs.dev/) 7
- **CSS framework**: [Bootstrap](https://getbootstrap.com/) 5.3
- **Styling**: Sass (custom SCSS on top of Bootstrap)
- **JavaScript**: Vanilla ES modules (Bootstrap JS bundle only)
- **Deployment**: GitHub Pages (static site, no server required)

## Project Structure

```
myraharriscoaching.com/
├── src/                     # Source files (edit these)
│   ├── index.html           # Single HTML page — all content and <head> meta/schema
│   ├── main.js              # Entry point: imports Bootstrap JS + compiled SCSS
│   ├── scss/
│   │   ├── custom.scss      # Root stylesheet; imports Bootstrap + modules
│   │   ├── config/
│   │   │   ├── _colors.scss
│   │   │   ├── _spacing.scss
│   │   │   └── _typography.scss
│   │   └── modules/
│   │       ├── _global.scss
│   │       ├── _sections.scss
│   │       └── _sidenav.scss
│   └── assets/
│       └── img/             # profile.jpg, discussion.jpg, therapy.jpg, listening.jpg, favicon.ico
├── dist/                    # Build output (committed; served by GitHub Pages)
├── vite.config.js
├── postcss.config.js
└── package.json
```

> **Never edit `dist/` directly.** It is fully regenerated by `npm run build` from `src/`.

## Prerequisites

- [Node.js](https://nodejs.org/) (v18 or later recommended)
- npm (comes with Node.js)

## Getting Started

```bash
git clone https://github.com/bitPimps/myraharriscoaching.com.git
cd myraharriscoaching.com
npm install
npm run dev
```

The development server starts at `http://localhost:3000`.

## npm Scripts

| Script | Command | Description |
|--------|---------|-------------|
| `dev` | `vite` | Start local dev server with hot reload on port 3000 |
| `build` | `vite build --base=./` | Compile and minify into `dist/` for production |
| `preview` | `vite preview` | Serve the `dist/` build locally for final checking |

## Build & Deployment

```bash
npm run build
```

Output goes to `dist/` at the project root (one level up from `src/`, as configured in `vite.config.js`). The `dist/` directory is committed to the repository and served directly by GitHub Pages.

After building, commit both `src/` changes and the updated `dist/`:

```bash
git add src/ dist/
git commit -m "your message"
git push
```

## SEO & Schema.org Markup

Structured data (JSON-LD) is embedded in the `<head>` of `src/index.html`. The following schema types are present in a single `@graph` block:

| Schema Type | `@id` | Purpose |
|-------------|-------|---------|
| `WebSite` | `#website` | Site identity |
| `Person` | `#myra-harris` | Myra Harris as a credentialed expert (E-E-A-T) |
| `ProfessionalService` | `#business` | The coaching business, linked to `#myra-harris` as founder and employee |

Additional SEO in `<head>`:
- `<meta name="description">` — keyword-rich description for search snippets
- `<link rel="canonical">` — canonical URL
- Open Graph tags (`og:type`, `og:url`, `og:title`, `og:description`, `og:image`) — social sharing previews

### Future: Review schema

The site's testimonials are currently anonymous and unrated. Once the business collects reviewer first names and star ratings, add `Review` nodes linked to `#business` and an `aggregateRating` property on the `ProfessionalService` node to unlock Google rich results for ratings.
